# ADR-005 — Lens URL and on-device preference

## Status

Proposed (P01B) — OD-05/06/07

## Decision

- Recommended default lens: Explorer  
- Canonical URL: `?lens=` (+ optional `?focus=` / `?stanza=`)  
- Optional `sessionStorage` after explicit user choice; no accounts/cookies profiles  
- Preserve reading position and focus on switch  

## Consequences

Shareable SSR-friendly private URLs; P1-U07 satisfied.
