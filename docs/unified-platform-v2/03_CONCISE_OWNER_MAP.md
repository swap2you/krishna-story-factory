# Concise Owner Map

## Where the project is today

- **Done and live:** Krishna Story Library through Story 025. The release, CI, staging, production smoke, and Story 026 boundary were validated.
- **Done but invisible:** Knowledge infrastructure—private Studio, structured records, four age lenses, export paths, font/Unicode support, and access controls.
- **Not done:** the visible Knowledge catalog/pages, Learning resources, Vāṇī, publishing outputs, controlled audio/scheduler, and the research lane for 3D.

## What this one package tells Cursor to build

1. Make Bhāva visibly function as a four-pillar platform, with honest available/planned states.
2. Turn the Knowledge foundation into a source-led public product only where records are truly ready.
3. Build Learning and publication outputs from those approved records.
4. Build Vāṇī and a controlled audio/scheduler foundation without fake quotes, voice imitation, or automatic publishing.
5. Prepare 3D/motion as a separate governed experiment, not a public distraction.

## Why it will not become another endless loop

Cursor gets the full remaining program, a locked visual/design target, exact quality gates, one continuous `develop` workflow, bounded root-cause repair, staging evidence, and one final promotion. It should not ask for a new prompt after every internal milestone. It pauses only for a real missing source/access/security/destructive-action blocker and returns one consolidated report.

## What you should expect to see after the program

- A home page that shows Bhāva as more than Stories.
- Clear Library, Knowledge, Learning, and Vāṇī surfaces.
- Real, reviewed Knowledge pages where sources are adequate.
- Usable teacher/family/learning resources derived from approved records.
- An internally controlled production process, while private material remains private.
