# Cursor Final Response — Required Concise Format

1. **Outcome:** CLOSED / BLOCKED / ROLLED_BACK.
2. **Refs:** start `develop`, final `develop`, `main`, deployed SHA, tags/content digests.
3. **Delivered:** five bullets maximum describing the visible user-facing result.
4. **Validation:** local tests, CI, staging, production, browser, accessibility, exports, source/privacy/security verdicts.
5. **Boundary:** public records/routes and denied private/draft routes.
6. **Evidence:** final cumulative ZIP path + SHA-256; milestone ZIP paths + SHA-256.
7. **Blocked items:** exact record/feature, missing proof, public impact, safe next action; state `NONE` if none.
8. **Send ChatGPT/CoWork:** exact ZIP, release ledger, final handoff, traceability, staging/production evidence, and screenshots paths.
