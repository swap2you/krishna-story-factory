# Visible Product Specification

## Design language

Use the locked Board B editorial-gouache direction throughout:

- deep navy, muted gold, ivory/cream, restrained saffron/lotus/sage;
- mature devotional editorial hierarchy, generous breathing room, quiet texture;
- real Unicode text for Devanāgarī, IAST, translations, and citations;
- mobile-first reading; no dashboard clutter, neon gradients, photoreal deity art, generic AI gloss, or scroll/cursor gimmicks.

## Public information architecture

| Surface | Required user value | Must not do |
|---|---|---|
| Home | Explain Bhāva and guide visitors to the four pillars; feature Stories and only approved current material | Pretend planned collections are available |
| Library | Show active Krishna Story Library, clear shelves, publication state, and resource formats | Expose private source originals or blank shelves as content |
| Knowledge | Explain guided devotional study; catalog genuine approved records with filters/search only where data exists | Publish roadmap/draft/restricted records |
| Learning | Offer clear audience pathways: children/youth, families, Sunday School, teachers, preachers, Gurukula/homeschool | Require child accounts or collect DOB/data |
| Prabhupāda Vāṇī | Present verified teaching in context, with exact source/review state and related study | Create quote-card fragments, impersonation, or unverified transcript claims |
| Record page | Purpose, real structured text/source, lens controls, focus mode, context, practice, sources/reviews, downloads when validated | Make an image the authoritative text or invent unavailable downloads |
| Studio | Private status and evidence workspace for roadmap/drafts/reviews/queues | Be reachable from public navigation or external requests |

## Home-page success test

A first-time visitor must understand in less than a minute:

1. Bhāva contains more than stories.
2. Stories 001–025 are actively available.
3. Knowledge is source-led, not a random blog.
4. Learning serves children, families, teachers, and communities.
5. Materials that are still being prepared are named honestly rather than disguised as missing pages.

## Canonical record page anatomy

1. Hero: title, one-sentence purpose, restrained approved art, status.
2. Lens selector: Little Learner / Explorer / Teen / Study.
3. Canonical text sequence: verified Devanāgarī, IAST, English, optional meanings.
4. Focus mode: optional, keyboard-safe, preserves context.
5. Context and learning: source-grounded explanation and original age-adaptive practice prompt.
6. Trust panel: sources, edition/locator, rights/use state, record version, review state, correction route.
7. Related approved material only.
8. PDF/DOCX only after exact export validation passes.

## Learning derivative anatomy

Every derivative must show or retain: canonical source record/version, audience, age range, objective, activity/assessment/answer-key relation, reviewer state, source and rights provenance, and export version. A printable is never a source of truth on its own.
