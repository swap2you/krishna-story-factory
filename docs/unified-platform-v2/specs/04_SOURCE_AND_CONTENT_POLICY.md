# Source, Content, and Publication Rules

## Source decision ladder

1. Use existing approved canonical packages first.
2. Use immutable private-library metadata and owner-supplied originals to establish a dossier, not as public runtime files.
3. Use official/authorized sources with exact locators and recorded permission/usage status.
4. Use secondary material only for discovery, never as enough proof for scripture/quotation/translation.

## Record gates

A record can become public only if all are PASS for the exact version:

- source dossier: exact edition/locator, text language state, checksum/reference, adequacy;
- claim map: every teaching claim linked to a source or explicitly marked Bhāva-original explanation;
- rights/use record: quotation/adaptation/translation/export/publication scope;
- canonical content and export hashes;
- editorial, devotional/scriptural, age-education, rights, and final-owner reviews;
- accessibility, privacy, security, and visual/export validation.

No record may become public because it is "nearly ready," popular, or present in a roadmap.

## The 12 owner-supplied PDFs

Use the `source_inventory/OWNER_PDF_INVENTORY.csv` to reconcile names and analysis. The files are source candidates, not automatic publication licenses. Preserve bytes; do not commit, serve, OCR-replace, or add Bhāva/Dauji copyright markings to them.

Two files are image-only and require a supported OCR path before searchable derivative use:

- Who are you offending — HG Mahatma Dasa
- Dangers of Vaisnava Aparadha — HH Radhanath Swami

If no supported OCR path exists, record `OCR_PENDING`; this is not a reason to fabricate text.

## Original expression

Bhāva may create original explanations, activities, lesson plans, summaries, visual briefs, and learning prompts from verified facts. It must label original English renderings and educational adaptations as Bhāva-original and must not attribute them to Śrīla Prabhupāda, BBT, an author, or an organization that did not create them.
