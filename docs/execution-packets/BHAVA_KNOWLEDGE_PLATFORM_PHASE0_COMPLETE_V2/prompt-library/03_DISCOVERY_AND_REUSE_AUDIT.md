# Discovery and reuse audit

Use read-only specialist agents for: repository/schema/routes; UX/components/styles/assets/fonts; content/roadmap/source contracts; tests/accessibility/export/security. Do not let them edit shared files.

Inspect and evidence:

- all four pillar routes, navigation, search, sitemap, Studio/private auth/boundaries;
- 348 roadmap record location/count/states and why they are not public;
- canonical/competing schemas across JSON, TypeScript, Python, SQL;
- content block components, typography, Devanāgarī/IAST support, image pipeline, motion;
- existing PDF/DOCX/print functions and dependencies;
- source/corpus import/export contract and private-path leakage risks;
- reusable design/components versus placeholders/dead routes;
- existing tests and missing acceptance coverage;
- performance, privacy/tracking, security, accessibility, SEO, and browser risks;
- candidate source dossiers for the golden page and four confirmation pages.

Do not guess file paths or source availability. Separate `VERIFIED`, `REPORTED`, `PROPOSED`, and `UNKNOWN`.

`SOURCE_AND_REUSE_INVENTORY.md`, `ROUTE_COMPONENT_DATA_MAP.md`, `SCHEMA_DRIFT_REPORT.md`, `ROADMAP_VISIBILITY_REPORT.md`, `EXPORT_SPIKE_OPTIONS.md`, `SOURCE_AVAILABILITY.md`, risk register, Phase 1 scope recommendation, and exact unresolved owner decisions.
