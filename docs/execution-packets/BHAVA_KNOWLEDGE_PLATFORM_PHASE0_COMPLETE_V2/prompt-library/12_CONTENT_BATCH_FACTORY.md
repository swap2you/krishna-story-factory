# Controlled content batch factory

Do not use this prompt in Phase 1.

Freeze batch ID, item IDs, priorities, dossiers, rights states, template/prompt/model versions, required assets/reviewers, budgets, and exclusions. For a 25-item batch use review checkpoints at 5/15/25. For a 50-item batch use waves of 10 and checkpoints at 10/25/50.

Automation may prepare dossiers, private drafts, asset briefs, manifests, automated QA, and review queues. It may not invent missing source text, grant rights, approve devotional content, publish, deploy, or change public lifecycle.

Track throughput only with defect/reviewer capacity: source adequacy, claim coverage, Sanskrit verification, rights completeness, asset provenance, accessibility/export pass rate, review time, rework, and blocked reasons. Stop scale when recurring defects indicate template failure.

Consolidate batch fixes as `KB-xxx.1`; do not chase isolated edits. Owner accepts the whole batch before the next begins.
