# Bhāva Knowledge Platform — Phase 0 Complete Package V2

**Prepared:** 2026-08-06  
**Status:** design and execution package; implementation not yet authorized  
**Supersedes:** `BHAVA_KNOWLEDGE_FOUNDATION_PHASE0_V1` where this package is more specific  
**Immediate next milestone:** Phase 1 — Governed Visual Learning Page Pilot

## Outcome

This package converts the program into a controlled sequence that Cursor can execute one phase at a time. It includes the program roadmap, age-adaptive UX contract, source/content governance, multi-agent operating model, SDLC gates, evidence requirements, maintenance rules, and a complete prompt library.

It does **not** change the application, repositories, branches, schedulers, staging, production, Story Factory, or public content.

## Start in Cursor

1. Copy or extract this entire folder into the root of the local `krishna-story-factory` checkout under:
   `docs/execution-packets/BHAVA_KNOWLEDGE_PLATFORM_PHASE0_COMPLETE_V2/`
2. Open `prompt-library/00_CURSOR_STARTER.md`.
3. Paste only that starter prompt into Cursor.
4. Cursor must first execute discovery and return a Phase 1 plan/evidence baseline.
5. Do not authorize implementation until the owner approves the Phase 1 requirements and UX specification.

## What is locked now

- Four public pillars: Library, Knowledge, Learning, Prabhupāda Vāṇī.
- Ministry/private-corpus originals stay immutable, private, and outside the public repository.
- One canonical devotional record may have multiple age views and format derivatives.
- Ages 5–22 are served through progressive depth, not four duplicated content copies.
- Devanāgarī, IAST transliteration, and verified English translation remain real selectable/copyable text; never bake them into artwork.
- Human source, devotional, rights, and final publication approval are mandatory.
- Cursor is the only writing/implementation agent on a phase branch. Specialist agents are read-only advisers unless explicitly assigned non-overlapping generated artifacts.
- No staging or production promotion without explicit owner authorization.
- Audio, podcasts, and 3D remain future phases. Phase 1 is web pages plus PDF/DOCX-capable export.
