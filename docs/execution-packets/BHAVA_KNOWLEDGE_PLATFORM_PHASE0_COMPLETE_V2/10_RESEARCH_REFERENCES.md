# Current Research and Standards References

These sources informed the Phase 0 design. They are technical/product references, not devotional source material.

## Accessibility and international text

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) — current W3C accessibility conformance target.
- [What is new in WCAG 2.2](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/) — focus and target-size changes.
- [WCAG2ICT](https://www.w3.org/WAI/standards-guidelines/wcag/non-web-ict/) — applying WCAG concepts to non-web documents/software.
- [Devanāgarī Script Resources](https://www.w3.org/TR/deva-lreq/) — layout/presentation resources for web and e-books.
- [WAI Images Tutorial](https://www.w3.org/WAI/tutorials/images/) — informative, decorative, functional, and complex image alternatives.
- [Reduced motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion) — honoring user motion preferences.

## Print/export

- [CSS printing](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Printing) — print styles and page media.
- [CSS paged media](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Paged_media) — page areas, breaks, left/right pages.
- [`@page`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40page) and [`break-inside`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/break-inside) — modern print controls.

## Child privacy and age-aware design

- [FTC COPPA Rule](https://www.ftc.gov/legal-library/browse/rules/childrens-online-privacy-protection-rule-coppa) — U.S. child-data requirements.
- [FTC Children's Privacy](https://www.ftc.gov/business-guidance/privacy-security/childrens-privacy) — current compliance guidance.
- [ICO Age Appropriate Design Code](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/childrens-information/childrens-code-guidance-and-resources/age-appropriate-design-a-code-of-practice-for-online-services/) — best interests and privacy-by-default benchmark.

## Existing application and future media

- [Next.js App Router documentation](https://nextjs.org/docs/app) — current official framework guidance; Phase 1 still preserves the installed project version.
- [NotebookLM Audio Overview help](https://support.google.com/gemininotebook/answer/16212820?hl=en) — AI-host discussions derived from uploaded sources.
- [NotebookLM Audio Overview customization](https://blog.google/innovation-and-ai/products/notebooklm-update-october-2024/) — steering focus/expertise of AI hosts.

## Application rule

Current does not mean “upgrade everything.” Cursor must audit the installed stack, security support, migration cost, and existing contracts. Upgrade only when required by the approved phase and backed by tests/rollback.
