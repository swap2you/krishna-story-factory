# Bhāva V1.5 Design System

## Brand

- Name: **Bhāva**
- Tagline: Timeless devotion for growing hearts and minds.
- Supporting: Stories, scripture, practice, and learning paths for children, youth, families, and teachers.

## Typography (licensed / open-source)

| Role | Font | CSS variable |
|------|------|--------------|
| Brand display wordmark | Tillana (Google Fonts) | `--font-brand-display` |
| Literary headings | Fraunces | `--font-display` |
| Body / UI | Source Sans 3 | `--font-body` |

**Samarkan:** Not embedded. No unofficial download. `--font-brand-display` is the future licensed Samarkan webfont slot.

## Type scale

- Display hero: `clamp(3rem, 6vw, 6rem)` via brand kicker / hero heading
- H1: `clamp(2.5rem, 4.5vw, 4.75rem)`
- Body: 1rem–1.125rem; long-form Knowledge ≥16–18px
- Reading width: ~60–72ch

## Logo lockup

- Icon mark + live HTML `Bhāva` wordmark + optional `Devotional learning`
- Desktop icon ~44px; mobile ~38px; supporting line hides on narrow screens
- No tiny cropped raster wordmark in the header
