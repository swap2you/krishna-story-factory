# Draft scaffold template v1 (private)

Produce a private draft **metadata** record only:

- id, title, kind, lifecycle=`draft`, visibility=`private`
- source_status=`SOURCE_INCOMPLETE` unless already a published Bhāva-original guide
- missing_fields when scripture is required
- never invent Devanāgarī, IAST, or English verse bodies
- never set `public_allowed=true` without dossier evidence

This template has **zero** approval, merge, deploy, or publication authority.
