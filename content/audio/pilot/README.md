# Audio / podcast pilot scaffold (Unified Platform M4)

Private dry-run lane for **educator-host discussions** about approved source packs.

## Hard rules

- **Educator-host only.** Neutral host framing discussing approved packs — not Śrīla Prabhupāda voice, not celebrity imitation.
- **No voice clone.** Do not clone Prabhupāda's voice or any rights-holder voice.
- **No auto publish.** Episodes stay draft / dry-run until independent rights, transcript-equivalence, and listening QA pass.
- **AI-educational disclosure required** on any generated host narration or assistive scripting.
- **Approved packs only.** Episode packs may reference Knowledge/Vāṇī packages that already cleared private source gates — never invent quotations to fill audio.

## Files

| File | Role |
| --- | --- |
| `episode.schema.json` | Field contract for a future episode pack |
| `manifest.json` | Pilot registry — empty episodes, `dry_run_scaffold` status |

## Operator posture

Treat this folder as research/scaffold. Running synthesis or publishing is out of scope for the M4 scaffold.
